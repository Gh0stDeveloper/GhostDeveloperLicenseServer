Hex Tunnel centraliza la instalación y administración de servicios de red en una VPS mediante licencias vinculadas, autorizaciones RSA, paquetes privados y actualizaciones controladas.

# Ejecutar como usuario con sudo
sudo bash -c 'command -v curl >/dev/null 2>&1 || { apt-get update -y && apt-get install -y curl ca-certificates; }; curl -fsSL https://ghostdeveloper.duckdns.org/install.sh -o /tmp/hextunnel-install.sh && chmod 700 /tmp/hextunnel-install.sh && exec /tmp/hextunnel-install.sh install'

# Después de instalar
sudo hextunnel-upgrade
sudo hextunnel-license status

Cadena privada y verificable

Cada instalación obtiene una autorización temporal antes de recibir el paquete. La key completa no se almacena en texto plano en el servidor de licencias.

01

Licencia vinculada

La activación se asocia a la IP pública y respeta vencimiento, estado y límite de activaciones.

02

Autorización RSA

El instalador verifica una respuesta firmada y una clave pública fijada mediante SHA-256.

03

Descarga de un solo uso

Los enlaces son temporales, privados, vinculados a IP y se invalidan después de utilizarse.

04

Integridad del paquete

El archivo privado se valida con SHA-256 antes de extraer o ejecutar cualquier componente.

05

Renovación automática

La instalación conserva un token de activación y renueva periódicamente su lease mediante systemd.

06

Actualización controlada

hextunnel-upgrade vuelve a autorizar la VPS y descarga únicamente la release activa.

Diseñado para una VPS dedicada

Importante

Hex Tunnel modifica servicios de red, firewall, puertos, SSH y componentes del sistema. Debe instalarse en una VPS amd64/x86_64 destinada especialmente a Hex Tunnel, no en el servidor donde se ejecutan el bot, la API, una web o aplicaciones críticas.

Sistemas

Debian 12, Ubuntu 22.04 LTS y Ubuntu 24.04 LTS.

Arquitectura

amd64/x86_64. El instalador rechaza ARM64 para evitar instalaciones incompatibles.

Acceso

Usuario con sudo o root, conexión a Internet estable y una licencia vigente emitida por TeleBotGen.

Desarrolladores

Hex Tunnel mantiene el crédito visible en el bot, el panel y la documentación pública.
